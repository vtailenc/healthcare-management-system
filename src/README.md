# Sample source modules

The folders in `src/` contain small, standalone examples for the demo's
patients, doctors, appointments, and billing areas. They use fictional,
in-memory data and do not connect to the API or database.

Run examples from the repository root:

```bash
python src/patients/sample_patients.py
python src/doctors/sample_doctors.py
python src/appointments/sample_appointments.py
python src/billing/sample_billing.py
```

These are illustrative starting points, not production healthcare components.
Do not use real patient information.
